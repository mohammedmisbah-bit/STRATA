## 🔐 Environment Variables Security

### ✅ Server-Only Variables (SECURE)
The following variables are **NEVER exposed to the client**:
- `GROQ_API_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

These are:
- Read only by server functions via `process.env`
- Protected by the `SERVER_ONLY_KEYS` allowlist in `vite.config.ts`
- Never substituted into client bundles
- Set in Netlify Dashboard (see instructions below)

### Client-Accessible Variables
Only variables prefixed with `VITE_*` are available to the client browser.

## 📦 Deployment Steps

### Option 1: Deploy via Netlify CLI

```bash
# Install Netlify CLI (if not already installed)
npm install -g netlify-cli

# Login to Netlify
netlify login

# Initialize site (first time only)
netlify init

# Deploy to production
netlify deploy --prod
```

### Option 2: Deploy via Git Integration

1. **Push to GitHub/GitLab/Bitbucket**
   ```bash
   git add .
   git commit -m "Configure Netlify deployment"
   git push origin main
   ```

2. **Connect to Netlify**
   - Go to https://app.netlify.com/
   - Click "Add new site" → "Import an existing project"
   - Select your Git provider and repository
   - Netlify will auto-detect the build settings from `netlify.toml`

3. **Configure Environment Variables**
   - Go to **Site settings → Environment variables**
   - Add the following variables:
     - `GROQ_API_KEY`: Your Groq API key
     - `SUPABASE_SERVICE_ROLE_KEY`: Your Supabase service role key
   - Click **Save**

4. **Deploy**
   - Netlify will automatically build and deploy
   - Future commits to `main` will trigger automatic deployments

## 🛠️ Troubleshooting

### Build Fails
- Check build logs in Netlify dashboard
- Verify all dependencies are in `package.json`
- Ensure Node.js version matches (Netlify uses Node 18+ by default)

### Environment Variables Not Working
- Verify variables are set in Netlify Dashboard
- Check variable names match exactly (case-sensitive)
- Redeploy after adding/changing variables

### 404 Errors on Routes
- Verify `netlify.toml` redirects are configured correctly
- Check that `publish = "dist/client"` is set

### Server Function Errors
- Check function logs in Netlify dashboard: **Functions → server**
- Verify environment variables are accessible
- Check for any console.error() output
